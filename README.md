# 屏幕操作控制面板

一个功能强大的屏幕操作自动化工具，支持坐标收集、消息发送、群控等功能，提供现代化的Web界面进行操作管理。

## 功能特性

### 核心功能
- **坐标收集**：收集屏幕上的公共点（6个）和设备特定点（3个）
- **消息发送**：向指定设备发送消息
- **群发模式**：使用公共点快速群发消息到多个设备
- **设备管理**：查看和管理已保存的设备信息

### 高级功能
- **话术管理**：支持多个类目的话术管理，方便快速选择和发送
- **群控功能**：根据类目概率自动向所有设备群发消息
- **定期发送**：定时向指定设备发送消息，支持自定义时间间隔
- **快捷停止**：支持ESC键快速停止正在运行的群控和定期发送任务

### 界面特性
- 现代化侧边栏导航设计
- 深色主题，视觉效果美观
- 响应式布局，支持多种屏幕尺寸
- 实时状态显示和反馈

## 技术栈

- **后端**：Flask（Python Web框架）
- **前端**：HTML5 + CSS3 + JavaScript
- **屏幕操作**：pynput（鼠标键盘控制）
- **数据存储**：JSON文件（groups.json、话术.json）

## 使用指南

### 坐标收集

1. **收集公共点**
   - 点击"收集公共点"按钮
   - 在屏幕上依次点击6个位置
   - 完成后自动保存

2. **收集设备特定点**
   - 输入设备ID（如 group1、group2）
   - 点击"收集设备特定点"按钮
   - 在屏幕上依次点击3个位置
   - 完成后自动保存到对应设备

### 发送消息

1. 在"发送消息"页面输入消息内容
2. 从下拉列表选择目标设备
3. 点击"发送消息"按钮

### 群发模式

1. 输入要群发的消息
2. 点击"群发消息"按钮
3. 系统会自动使用公共点依次点击发送

### 设备管理

1. 在"设备管理"页面查看所有已保存的设备
2. 点击"刷新设备列表"更新数据
3. 点击设备旁边的"×"按钮删除设备

### 话术管理

1. 从下拉列表选择类目
2. 输入新话术内容
3. 点击"添加话术"保存
4. 在话术列表中可以查看和删除话术

### 群控功能

1. 在"群控功能"页面设置各话术类目的概率（0-100%）
2. 确保总概率为100%
3. 点击"开始群控"按钮
4. 系统会根据概率自动选择话术并发送到所有设备
5. 按ESC键或点击"停止群控"按钮可随时停止

### 定期发送

1. 输入要定期发送的消息
2. 选择目标设备
3. 设置时间间隔（秒）
4. 点击"开始定期发送"按钮
5. 按ESC键或点击"停止定期发送"按钮可随时停止

## 数据文件

### groups.json
存储设备坐标信息，结构如下：
```json
{
  "common_points": [[x1, y1], [x2, y2], ...],
  "group_points": {
    "group1": [[x1, y1], [x2, y2], [x3, y3]],
    "group2": [[x1, y1], [x2, y2], [x3, y3]]
  }
}
```

### 话术.json
存储话术数据，结构如下：
```json
{
  "类目1": ["话术1", "话术2", ...],
  "类目2": ["话术1", "话术2", ...]
}
```

## API接口

### 坐标收集
- `POST /api/collect/common` - 开始收集公共点
- `POST /api/collect/group` - 开始收集设备特定点
- `GET /api/status` - 获取收集状态

### 消息发送
- `POST /api/send` - 发送消息到指定设备
- `POST /api/click-all` - 群发消息

### 设备管理
- `GET /api/groups` - 获取设备列表
- `DELETE /api/groups/<group_id>` - 删除设备

### 话术管理
- `GET /api/scripts/categories` - 获取话术类目列表
- `GET /api/scripts/<category>` - 获取指定类目的话术
- `POST /api/scripts/<category>` - 添加话术
- `DELETE /api/scripts/<category>` - 删除话术

### 群控功能
- `POST /api/batch/start` - 开始群控
- `POST /api/batch/stop` - 停止群控
- `GET /api/batch/status` - 获取群控状态

### 定期发送
- `POST /api/scheduled/start` - 开始定期发送
- `POST /api/scheduled/stop` - 停止定期发送
- `GET /api/scheduled/status` - 获取定期发送状态

## 注意事项

1. **权限要求**：程序需要管理员权限才能执行鼠标点击操作
2. **屏幕分辨率**：坐标收集后，请保持屏幕分辨率不变
3. **窗口位置**：确保目标应用窗口位置固定
4. **概率设置**：群控功能的概率总和应为100%
5. **快捷键**：ESC键可快速停止群控和定期发送任务
6. **数据备份**：定期备份 groups.json 和 话术.json 文件

## 常见问题

### Q: 收集的坐标不准确怎么办？
A: 确保目标应用窗口位置固定，屏幕分辨率不变，重新收集坐标。

### Q: 群控功能没有发送消息？
A: 检查设备列表是否正确，类目概率设置是否合理，话术数据是否存在。

### Q: 定期发送停止了？
A: 检查设备是否存在，消息内容是否正确，时间间隔设置是否合理。

### Q: 如何修改端口？
A: 在 app.py 最后修改 `app.run()` 的参数，如 `app.run(port=8080)`。
